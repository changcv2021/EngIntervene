# 匿名代码附件说明

本目录只包含代码、配置、固定split/采样ID与说明，不含作者身份、学校、账号、
邮箱、服务器绝对路径、密钥、实验日志、模型权重、题目图像或金标准答案。

流程：加载本地数据集 → 准备Train/Validation目标 → Format/Industry两种LoRA
→ 在相同Test上推理 → 独立Qwen3.5-4B评分 → 汇总四任务及Challenge。
完整命令、输入格式及限制见英文README。

直接复用已经整理的 `benchmarkanon/EngIntervene` 数据集，不重新制作题目或图片。
如已持有匿名数据交付包，答案和评分标准直接使用其中的
`private_scoring/labels.jsonl` 与 `private_scoring/rubrics.jsonl`，不要混入代码附件。
注意：Hugging Face 的 `test` 是完整3,229题；SFT实验的 Test 是其中来源隔离的1,306题。

- 训练：3个模型×2个条件，共6次单种子实验；不是3个条件各训练一次。
- 划分：原有227个来源连通组，1615/308/1306，保留原始分配，不重新随机切分。
- 训练模块来自历史完成实验，保留loss掩码、优化器、学习率、随机种子、图像预算。
- 评分器保留现有T1解析和T2–T4逐项评分逻辑；T4同时输出Atomic和Strict。
- 测评输入侧不读取答案。SFT和评分需要另行取得labels/rubrics；公开输入集本身不够。
- 本次没有重新运行六项GPU训练，没有调用任何付费API，没有上传任何仓库。
- 跨平台包装、新数据加载与推理调度不能被说成所有历史模型后端均已重新验证。
- Text-only不输入图片、不补图片描述、不删除数据集图片；shuffle仅在同任务同领域换图。
- 不附带机构云API部署脚本；外部模型输出可转换为ID+response后接入统一评分。
- 原子评分仍是自动评分，不意味着新增人工复核，既有rubric问题不会被隐藏。

请仅上传经过扫描的代码ZIP。数据、模型、日志和本地个人配置应分开保管。
代码按维护者选择采用MIT许可证，署名为匿名的EngIntervene contributors。
